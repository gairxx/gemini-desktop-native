Here is how you query the org.freedesktop.AI.Control interface via pydbus:

from pydbus import SessionBus
bus = SessionBus()
gemini = bus.get("org.freedesktop.AI.Control", "/org/freedesktop/AI/Control")
state = gemini.ExecuteTool("get_state", "{}")

Installation & Quickstart

Deploy directly via the one-line curl installer (prebuilt release bundle) or grab the bundle manually.

Method 1: One-Line Installer (Recommended)

# Installs the prebuilt bundle from the latest GitHub release

$ curl -fsSL https://raw.githubusercontent.com/gairxx/gemini-desktop-native/main/install.sh | bash

# Launch client natively

$ flatpak run org.native.GeminiDesktop
Runtime: org.gnome.Platform//46 Verified Build
Method 2: Download the Bundle
$ curl -fL -O https://github.com/gairxx/gemini-desktop-native/releases/latest/download/org.native.GeminiDesktop.flatpak
$ flatpak install --user ./org.native.GeminiDesktop.flatpak
$ flatpak run org.native.GeminiDesktop
Dependencies: WebKitGTK 6.0, Libadwaita 1.5 Release Bundle

Wayland, X11 & Background Autostart Tips

Gemini Desktop Native defaults to native Wayland rendering with fallback to XWayland. To launch into the system tray silently at session startup, pass the --hidden flag in your ~/.config/autostart desktop entry.

Remote Control via D-Bus (org.freedesktop.AI.Control)

Gemini Desktop Native exports a standardized D-Bus interface on the session bus at path /org/freedesktop/AI/Control. This enables seamless integration with Model Context Protocol (MCP) servers, Raycast-style launchers, terminal scripts, and custom desktop automation.

lock Note: the interface is local-only — usable from the machine the app runs on, never exposed to the Gemini web page.

gdbus Command-Line Examples

Test and script native controls directly from your shell using standard Linux freedesktop utilities.

info Inspect Client State with get_state 
gdbus call --session \
  --dest org.freedesktop.AI.Control \
  --object-path /org/freedesktop/AI/Control \
  --method org.freedesktop.AI.Control.ExecuteTool get_state '{}'

# Response output dictionary:

({'visible': <true>, 'url': <'https://gemini.google.com/app'>, 'can_go_back': <false>, 'can_go_forward': <false>, 'spotlight_active': <false>},)
Protocol: FreeDesktop Session Bus IPC
bolt Inject Prompt via send_prompt 
gdbus call --session \
  --dest org.freedesktop.AI.Control \
  --object-path /org/freedesktop/AI/Control \
  --method org.freedesktop.AI.Control.ExecuteTool \
  send_prompt "Summarize recent git commits in markdown"

# Response:

()  # Composer focused and prompt executed successfully.
Execution: Sub-millisecond IPC response

MCP Server & GNOME Shortcut Integration

Bind native prompts to custom keyboard shortcuts or expose Gemini as an MCP tool.

# Quick Bash alias for ~/.bashrc or GNOME Custom Shortcut
alias ask-gemini='function _g() { gdbus call --session --dest org.freedesktop.AI.Control --object-path /org/freedesktop/AI/Control --method org.freedesktop.AI.Control.ExecuteTool send_prompt "$1"; }; _g'

# Usage:
$ ask-gemini "Explain the diff between GTK4 and Qt6 signals"
